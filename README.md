# 🎲 Sorteador de Números

Uma aplicação web para realizar sorteios de números de forma simples, rápida e personalizada. Desenvolvida como parte de um desafio prático da formação da Rocketseat, com foco em lógica de programação, manipulação do DOM e validação de dados.

## ✨ Sobre o projeto

O Sorteador de Números permite que o usuário defina a quantidade de números que deseja sortear, escolha um intervalo personalizado e determine se os resultados podem se repetir.

O projeto foi desenvolvido com HTML5, CSS3 e JavaScript puro, sem dependência de frameworks, priorizando uma estrutura organizada, uma interface minimalista e uma experiência de uso intuitiva.

## 🚀 Funcionalidades

- **Quantidade personalizada:** escolha quantos números deseja sortear.
- **Intervalo configurável:** defina os valores mínimo e máximo.
- **Sorteio sem repetição:** gere resultados únicos dentro do intervalo.
- **Sorteio com repetição:** permita que um mesmo número apareça mais de uma vez.
- **Validação de dados:** identificação de campos vazios, valores inválidos e intervalos incompatíveis.
- **Mensagens interativas:** feedback visual para erros e sorteios concluídos.
- **Animações CSS:** exibição gradual dos números sorteados.
- **Atualização dinâmica:** novos sorteios substituem os resultados anteriores.
- **Interface responsiva:** adaptação para diferentes tamanhos de tela.

## 🛠️ Tecnologias utilizadas

- HTML5 — estrutura e semântica da aplicação.
- CSS3 — estilização, layout responsivo e animações.
- JavaScript — lógica de sorteio, validações e manipulação do DOM.
- Git e GitHub — versionamento e gerenciamento do projeto.

## 🧠 Conceitos praticados

Durante o desenvolvimento, foram explorados conceitos fundamentais do desenvolvimento web:

- Manipulação de elementos HTML com `querySelector`.
- Eventos de formulário com `addEventListener`.
- Validação e conversão de valores numéricos.
- Geração de números aleatórios com `Math.random()` e `Math.floor()`.
- Arrays, funções e estruturas de repetição.
- Uso de `Map` para realizar sorteios sem repetição de forma otimizada.
- Manipulação dinâmica do DOM.
- Promises e funções assíncronas com `async/await`.
- Animações e responsividade com CSS.

## 🎯 Objetivo do projeto

Este projeto faz parte da minha jornada de aprendizado em desenvolvimento web e representa uma oportunidade de aplicar conceitos fundamentais na construção de uma aplicação funcional.

Mais do que implementar um sorteio, o desafio permitiu praticar validações, organização de código, manipulação do DOM e cuidados com a experiência do usuário.
